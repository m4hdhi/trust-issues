Backend server

خادم الفحص

Links are checked against this Trust Issues server. Use http://localhost:8000 while developing, or your Railway URL (for example https://trust-issues.up.railway.app) in production.

Language display

لغة العرض

Used for link badges, warnings and the toolbar popup.

Where it protects you

أين تحميك الإضافة

  • Google Search marks official, suspicious and scam results, including sponsored ones.
  • Google Maps checks the website on business listings and flags the phone number of fake ones.
  • WhatsApp Web checks links inside your chats.
  • Clicking a scam link opens a full-screen warning before anything loads.
  • Right-click any link and choose Check link with Trust Issues for a deep scan.
